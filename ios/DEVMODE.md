# 개발자 모드 (iOS) — 테스트용, 삭제 가능

기록 → 프로필 수정 → 로그아웃 아래 **개발자 모드** 토글로 켠다. 켜지면 모든 탭 위에
떠 있는 HUD 로 배터리 소모·GPS 신호·통신 상태를 본다. 드래그로 옮기고, ⌃ 로 접는다
(개발자 모드 자체는 프로필 토글로 끈다).

> 2026-07-29 재구성 — **배터리 계측기**로 전환. 지도·콘솔·빌드 구획을 뺐다.
> 뺀 이유: 지도는 배터리와 무관, 콘솔(`dup2` 가로채기)은 그 자체가 CPU·메모리를 써서
> 측정값을 오염, 빌드 정보는 스플래시 좌측 상단 표시(`build N · MM-dd HH:mm`)와 중복.

## 무엇을 보나

| 구획 | 값 | 왜 |
|---|---|---|
| **배터리** | 잔량 %, 충전/방전, 저전력 모드 | 기준값. 저전력 모드는 GPS·통신 거동을 바꾸므로 함께 봐야 한다 |
| **계측** | 경과 시간, 소모 %, **시간당 소모율(%/h)** | 이 HUD 의 존재 이유. 나머지는 전부 이 값을 해석하려고 있다 |
| **GPS** | 신호 막대(±m), 고도±, 정확도 모드, fix 빈도, 마지막 수신, 좌표 | 백그라운드 위치가 소모의 주범 |
| **통신** | 온/오프라인, 설치 팩 수 | 네트워크도 배터리를 쓴다. 오프라인 등반이 실제로 통신을 끊는지 확인 |

## 사용법 — 정확도 등급별 소모 비교

1. HUD 의 **[리셋]** 을 누르고 등반 시작
2. **10분이 지나야 `%/h` 가 나온다** — 잔량이 5% 단위로만 변해 그전에는 0%/5% 로 튄다
3. GPS **모드** 행을 탭하면 정확도가 `Best → 10m → 100m` 로 순환하고 **계측이 자동 리셋**된다
4. 같은 코스에서 등급만 바꿔 `%/h` 를 비교한다

## 구성

전용 폴더 `HiHeight/DevMode/` 에 모여 있다.

| 파일 | 역할 |
|---|---|
| `DevStore.swift` | 싱글턴 상태 + 배터리 샘플링(10초 타이머) + 자체 `CLLocationManager` |
| `DevHUD.swift` | 떠 있는 패널 UI (배터리·계측·GPS·통신 4구획) |
| `DevGate.swift` | 프로필 화면 진입 토글 |

## 완전 삭제 절차

```bash
# 1) 폴더 삭제
rm -rf ios/HiHeight/DevMode

# 2) 표식 붙은 삽입점 제거 — 전부 단독 줄이라 그 줄만 지우면 된다
grep -rn "DEVMODE" ios --include='*.swift' --include='*.yml' --include='*.sh'
#   ProfileEditView.swift DevGate() 한 줄
#   ContentView.swift     .overlay { DevHUD() } 한 줄
#   project.yml           GIT_COMMIT 기본값 · GitCommit info 키 (각 한 줄)
#   testflight.sh         COMMIT= · GIT_COMMIT= (각 한 줄, 남겨도 무해)

# 3) 프로젝트 재생성 (DevMode/ 는 글롭 포함이라 자동 제외)
cd ios && xcodegen generate
```

Swift 삽입점이 **2곳**이다(2026-07-29 재구성으로 `MapView.swift` 의 지도 통지 한 줄이 사라졌다).

## 알아둘 것

- **배터리는 실기기에서만 측정된다.** 시뮬레이터의 `UIDevice.batteryLevel` 은 `-1` 을 돌려준다
  (HUD 는 "미지원 — 실기기에서만 측정됨" 으로 표시).
- **잔량 정밀도는 5% 단위**다. 30분짜리 짧은 측정은 0% 또는 5% 로 뭉툭하게 나온다 —
  그래서 `%/h` 는 10분 경과 후에만 계산한다.
- **소모량은 기기 전체 값**이다. 앱별 소비 전력을 조회하는 공개 API 는 iOS 에 없다.
  측정 중 다른 앱을 쓰면 그 소모도 포함된다.
- **충전 중에는 측정하지 않는다**(소모 행이 "충전 중 — 측정 불가").
- **GPS 신호세기 raw 값은 iOS 가 공개하지 않는다.** 위성 SNR 을 주는 안드로이드 `GnssStatus`
  같은 API 가 없어, `horizontalAccuracy`(±m)를 4단계로 등급화해 막대로 보여준다.
  `■■■■ 최상`=±5m 미만, `■■■□ 양호`=10m, `■■□□ 보통`=20m, `■□□□ 약함`=50m.
- **GPS 는 DevStore 자체 매니저**라 등반 중이 아니어도 좌표가 뜬다. 권한은 앱이 이미
  등반용으로 받는 것과 같다. 모드 변경도 이 매니저에만 적용되며 **등반 트래킹에는 영향이 없다**.
- 개발자 모드를 끄면 `isBatteryMonitoringEnabled` 도 원복된다.
